# Antigravity Web CAD

**現在のバージョン: v5.1（2026年9月25日リリース）**

[![CI](https://github.com/taka2560-commits/webCAD/actions/workflows/ci.yml/badge.svg)](https://github.com/taka2560-commits/webCAD/actions/workflows/ci.yml)

スマートデバイスやPCの両方で利用できるWebブラウザベースの2D CADアプリケーションです。
測量図面や建設現場での利用に特化した設計となっており、特別なソフトのインストールなしで、ブラウザから即座に図面を開いて確認・編集・計測が可能です。

**[https://antigravity-web-cad.vercel.app](https://antigravity-web-cad.vercel.app)**

## ✨ 主な特徴

- **DWG & DXF の高精度読み込み** 
  - `libredwg-web` (WebAssembly) を搭載し、R2004〜R2018など様々なバージョンのDWGファイルをブラウザ上で直接・高精度にパースして描画します。
- **測量座標系に特化したUI**
  - 画面の「縦方向をX座標」「横方向をY座標」として扱う測地座標系表示に完全対応。UCS（ユーザー座標系）を設定しての任意座標での作業も可能です。
  - コマンド欄の座標も「X,Y」（X＝北・Y＝東）の順で入力します（v4.9.1 で画面の表示・SIMA と同じ順に統一）。
- **トータルステーション連携（v5.1）** — ⋯ メニューの「📡 TS連携」（ソキアの SDR 形式）
  - **SDR ファイル**: 機械の現場データ（.sdr。SDR33・SDR2x）を 📁開く で開くと、器械点・後視・目標高・観測（正・反・補正済み）から座標を計算して測点にします。測点を **SDR33 で書き出し**（既知点・杭打ち点として機械で読み込む）。
  - **通信（Web Serial）**: PC の Chrome・Edge、Android の Chrome では USB ケーブル・Bluetooth で機械とつなぎ、機械の「通信出力（S type・SDR33）」を受信して図面に重ねて確認 → 取り込み。測点を「通信入力」へ送信（チェックサム・XON/XOFF 対応）。iPhone・iPad はファイルで受け渡し。
- **測量計算（v5.0）** — ⋯ メニューの「🧮 測量計算」
  - **求積（座標法）**: 区画の線か内側をタップすると、座標求積表（点名・X・Y・Yn+1−Yn−1・倍面積の項・辺長）と倍面積・面積・地積（0.01㎡／1㎡未満の切り捨て）を出します。求積表を図面に置く・辺長を記入・面積を記入・CSV 出力。
  - **逆計算**: 2点の ΔX・ΔY・水平距離・方向角（度 分 秒）。終点から続けて次の区間へ。
  - **点の追加**: 座標、方向角と距離、後視点と夾角（右回り）から測点を追加。
  - **交点**: 2直線（延長線上も）・方向角×2・距離×2（右／左を選ぶ）の交点を測点として追加。
  - 点は 📍 で図面の点をなぞって ☑確定（測点に吸い付き、点名もそのまま使う）、または点名・点番号・「X,Y」を入力。
- **測量データのやり取りと現在地（v4.4）**
  - **SIMA（.sim）・座標CSV** の読み込み・書き出しに対応。区画データ（D00〜D99）も扱えます。
  - **座標一覧**: 点・属性付きの測点ブロック・区画の頂点を一覧し、検索・タップで移動。閉じた線の面積（㎡）も表示。
  - **現在地（GNSS）**: スマホの位置情報を平面直角座標（19系）に換算して図面上に表示し、現在地に点を追加できます。
- **基点測定（v4.5）**
  - 基点を1つ決めると、そこから指・スナップ点までの **X距離・Y距離・直線距離** を画面に出したまま確認できます。画面を動かしても基点は残ります。
  - 「📐 記入」で、いま見えている測定値をそのまま寸法として記入できます。
- **フローティングパネルの移動（v4.5）**
  - 座標一覧・オプションなどのパネルは見出しをつまんで移動できます（位置は記憶。ダブルタップで中央に戻る）。
- **はじめての方向けの操作ガイド（v4.9）**
  - 練習用の図面で、実際に操作すると次へ進む **ツアー**（はじめてツアー・座標読取モード・機能別のミニツアー）。
  - コマンドの **手順カード**（操作に合わせて次の手順に変わる）と、つまずいたときの一言。右下の **？** からヘルプ。
- **スナップと点の指定の補助（v4.8）**
  - 端点・中点・中心・交点・垂線・近接点に加えて、**挿入点・接線・四半円点・延長・延長交点・図心・等分点**。楕円にも対応。
  - 線の上で少し止めると、その線を延ばした先（延長・延長交点・延長線上の垂線）が使えます。
  - **次の1点だけのスナップ指定**、重なった候補の**切り替え（Tab / ⇄）**、**2点の中点**、**相対入力**（北・東へ／距離・方向角）。
- **表示・操作の設定（v4.7）**
  - オプションの「表示・操作」で、ルーペの大きさ・倍率、座標の文字の大きさ・桁数、寸法の文字の大きさ・桁（v4.9.1）、スナップの吸着範囲を端末ごとに変えられます（ルーペと吸着範囲は見本つき）。
- **スマートフォンに最適化された操作性** 
  - 小さな画面でも正確にタップできる「拡大鏡（ルーペ）機能」や、キーボードが意図せず出現しない自動フォーカス解除など、現場でのスマホ操作を想定したUIを備えています。
- **PWA対応・自動アップデート（v3で強化）** 
  - ホーム画面に追加することで、ネイティブアプリのように全画面で利用可能です。
  - アプリを開くだけで最新版に自動更新されます。起動中に新しい版が届いた場合は「再読み込み」の案内が出ます。
  - 図面の読み書きライブラリをアプリに同梱しており、一度開いた端末なら**電波の無い現場でもDXF/DWGを開く・書き出す**ことができます（DWG読込エンジンはオプション画面から事前に端末へ保存することもできます）。
  - 作業中の図面は変更の15秒後（最長60秒）と、アプリを裏に回した瞬間に自動保存されます。
- **日本語テキストの高い互換性（v3）** 
  - DXFの文字コードを自動判定（UTF-8 / Shift-JIS）。MTEXTの書式コードや `\U+XXXX` 形式・`%%c` 等の特殊記号も正しく変換し、日本語の文字化けを解消しています。
- **新モバイルUI（v3で標準化）** 
  - iPhone縦持ちを基準に、上部バーを「ラベル＋カード」でグループ化し横1行スクロール化。左ツールバーは44pxアイコンレール＋`☰`でラベル付きパネルに展開。コマンドラインは32pxピルに収まり、タップで全ログを展開します。
  - 配色の役割を固定（青=座標系/ORTHO・緑=確定/保存/OSNAP・水色=寸法・黄=編集・赤=削除）し、現場での視認性を向上。
  - 設計資料: **[モックアップ](docs/mockups/Web%20CAD%20Mobile%20UI.html)** / **[モックアップV2](docs/mockups/ui-mock-mobile.html)** / **[UIデザインブリーフ](docs/mockups/claude-design-ブリーフ.md)**

## 📱 基本操作（画面の移動・拡大など）

### PCでの操作
* **画面の移動（パン）**: マウスの「ホイールボタン（中ボタン）」を押したままドラッグ。
* **画面の拡大・縮小（ズーム）**: マウスのホイール転がし。
* **図形の選択**: 左クリック（複数選択可）。何も選択していない状態でドラッグして離すと「範囲選択」になります。
  * **左から右へドラッグ（青枠）**: 枠内に完全に収まっている図形のみ選択（窓選択）。
  * **右から左へドラッグ（緑枠）**: 枠に少しでも触れている図形がすべて選択（交差選択）。

### スマートフォン（タブレット）での操作
* **画面の移動（パン）**: 2本指で画面に触れ、そのままスライドします。
* **画面の拡大・縮小（ズーム）**: 2本指でつまんだり広げたりします（ピンチイン・ピンチアウト）。
* **図形の選択**: 図形付近を1回短くタップします。
* **正確な位置の指定（ルーペ機能）**: 画面を1本指で長押ししながらスライドすると、指の上に拡大鏡（ルーペ）が現れます。指を離した場所が決定ポイントになります。
* **範囲選択**: コマンド実行前やコマンド待機時に1本指でスライドさせると枠が描画されます。

### 新モバイルUIの操作
* **ツールバーの展開**: 左レール上部の `☰` をタップするとラベル付きツールパネルが開きます。`◀` で折りたたみます。
* **コマンドライン**: 画面下部のピル（`● READY · …`）をタップで全ログ＋入力欄を展開。入力行右の `▼` で閉じます。
* **オプション（背景色）**: 上部バーの `⚙ オプション` から、キャンバス背景を **黒／グレー／白** に切り替え可能（選択は次回も保持）。白背景時はグリッド・十字線・白系の図形色を自動で暗色に補正します。
* **コマンド設定パネル**: `CIRCLE`/`RECTANG`/`OFFSET`/`ROTATE` 実行時に、数値（半径・幅×高さ・距離・角度）を入力できるフローティングパネルが表示されます。空欄のままなら従来のクリック作図になります。
* **ブロック・グループ**: DXF/DWGから取り込んだブロック（記号・測点など）や寸法はまとまり（グループ）として扱われ、**1つタップするとブロック全体が選択**されます。選択中は画面下の **選択アクションバー** から移動・複写・回転・削除・隠す・分解ができます。上部バーの `🧩`（ブロック管理）で、ブロック名ごとの表示/非表示・ズーム・一括選択ができます。部品を個別に編集したいときは「分解」、または `⚙ オプション` で「タップでブロック全体を選択」をOFFにしてください。
* **図面を開く**: 既に図面があるときは「置き換える」か「現在の図面に追加する」かを選べます。読み込み結果（個数・未対応数）は画面上部に一時表示されます。

## 🛠 主要コマンド一覧

画面下のコマンドライン、または左側のツールバーから実行します。

| コマンド | エイリアス | 概要 |
| :--- | :--- | :--- |
| **LINE** | `L` | 線分を描画します。（1点目と2点目を指定） |
| **CIRCLE** | `C` | 円を描画します。（中心点と半径を指定／設定パネルで半径を入力可） |
| **RECTANG** | `REC` | 長方形を描画します。（対角線を指定／設定パネルで幅×高さを入力可） |
| **ARC** | `A` | 円弧を描画します。（3点・中心などを指定） |
| **PLINE** | `PL` | 連続した線（ポリライン）を描画します。「完了」ボタンで確定します。 |
| **TEXT** | `T` | 文字を入力します。（プロパティから後で書き換え可能） |
| **HATCH** | `H` | 選択した閉じた図形（長方形・円など）を半透明で塗りつぶします。 |
| **POINT** | `PO` | 測量座標などで利用する「点」を描画します（ズームに連動しない一定サイズ）。 |
| **ERASE** | `E` | 図形を削除します。あらかじめ選択してから実行してもOKです。 |
| **MOVE** | `M` | 図形を別の場所へ移動します。（基点と目的点を指定） |
| **COPY** | `CO` | 図形をコピーします。（基点と目的点を指定） |
| **OFFSET** | `O` | 任意の距離を指定して、図形を平行に複写します。（設定パネルで距離を入力可） |
| **ROTATE** | `RO` | 図形を回転させます。（基点と参照角度を指定／設定パネルで角度を入力可） |
| **DIM** | - | さまざまな寸法記号（平行、角度、半径など）を引き出します。 |
| **UCS** / **WCS** | - | 任意の場所を原点(0,0)にする(UCS) / 本来の絶対座標に戻す(WCS)。 |
| **ZOOM** | `ZE` | 図面全体が画面に収まるよう表示位置を調整します。 |
| **GROUP** | `G` | 選択中の複数図形をグループ化します（まとめて移動・削除できます）。 |
| **UNGROUP** | `X` / `EXPLODE` | 選択中のグループ（取り込んだブロック含む）を分解して個別の図形にします。 |
| **BLOCKS** | - | ブロック管理パネルを開きます（種類ごとの表示/非表示・ズーム・一括選択）。 |
| **SHOWALL** | - | 非表示にした図形（取り込み時の円弧など）をすべて再表示します。 |
| **ERRORS** | `ERRLOG` | エラーログ（直近30件・端末情報つき）を表示します。不具合報告用にコピーできます。 |
| **COORDS** | `POINTS` / `ZAHYO` | 座標一覧を開きます（検索・タップで移動、CSV/SIMA出力）。 |
| **SIMAOUT** | `EXPORTSIMA` | 測点・区画を SIMA（Shift-JIS）で書き出します。 |
| **CSVOUT** | `EXPORTCSV` | 測点を座標CSV（点番号,点名,X,Y,標高）で書き出します。 |
| **GNSS** | `GPS` | 現在地の表示を開始/終了します（初回は系番号を選択）。 |
| **GNSSZONE** | - | 現在地の座標系（平面直角座標の系番号）を選び直します。 |
| **MEASURE** | `MEA` / `DIST` / `DI` | 基点測定。基点からのX距離・Y距離・直線距離を出したまま確認し、「記入」で寸法にできます。 |

## 🧑‍💻 開発者向け

```bash
npm install          # 依存ライブラリ（dxf-parser / dxf-writer / libredwg-web / vite）
npm run dev          # 開発サーバー（Service Worker は登録されず、常に最新のコードで動作）
npm run build        # 本番ビルド（dist/）
npm run preview      # 本番ビルドの確認（Service Worker・オフライン動作の検証はこちらで）
npm test             # 自動テスト（343件。アプリを jsdom 上で実際に動かして確認）
npm run lint         # 構文・未定義変数のチェック
npm run check        # lint → テスト → ビルドをまとめて実行（CI と同じ内容）
```

* **自動テスト**: `tests/*.test.cjs` は Node.js 標準の `node:test` で動きます。`tests/helpers/load-app.cjs` が index.html と `public/cad-*.js` をブラウザと同じ順序で jsdom 上に読み込むので、テストからアプリの関数・変数をそのまま呼べます（IndexedDB は fake-indexeddb で再現）。不具合を直すときは、先にそれを再現するテストを追加してください。
* **CI**: GitHub にプッシュすると `.github/workflows/ci.yml` が `npm run lint`・`npm test`・`npm run build` を実行します。
* **描画と変更の合図**: 図形や表示位置・選択が変わったら `render()`、カーソル・スナップ記号・ルーペなど重ね表示だけが変わるときは `renderOverlay()` を呼びます（重い図面では前回の画面を再利用します）。図形の座標を変えたら `delete e.bbox` と `_bumpGeomEpoch()` を行ってください（空間索引・描画キャッシュの作り直しの合図。編集前の `saveUndo()` でも進みます）。
* **図形の固有ID**: 各図形は `e.id`（数値）を持ちます。選択状態（`cmdState.selectedIndices` / `highlightIdx` など）は内部ではIDで保持し、読み出すとその時点の配列番号を返します。図形を複製するときは `id` を消してから追加してください（重複しても `ensureEntityIds()` が後ろ側に新しいIDを付けます）。

* **構成**: `index.html` と `public/cad-*.js`（通常のスクリプト）が本体です。外部ライブラリは `src/vendor.js` から Vite で同梱し、`window.DxfParser` / `window.Drawing` / `window.loadLibreDwg()` として公開しています。

  スクリプトは **すべて同じスコープ** に読み込まれるため、ファイルをまたいで関数・変数をそのまま呼び合います。**読み込み順（index.html の並び）と、名前が重ならないこと** が動作の前提です（`tests/structure.test.cjs` で自動確認）。

  | ファイル | 役割 |
  |---|---|
  | `cad-errors.js` | 未捕捉エラーの記録・通知（最初に読み込む） |
  | `cad-text-parse.js` | DXF文字列のデコード・MTEXT書式の除去 |
  | `cad-dimension.js` | 寸法（6種類）の作成・描画・編集、基点測定の表示 |
  | `cad-io.js` | DXF/DWG の読み込み・書き出し、ファイル選択 |
  | `cad-core.js` | 図形・画層・表示位置などの状態、図形の固有ID、グループ、共通UI、初期化、元に戻す/やり直し |
  | `cad-prefs.js` | 表示・操作の設定（ルーペ・座標の文字と桁・寸法の文字・吸着範囲）。`displayPref(名前)` で値を取り出す |
  | `cad-view.js` | 画面座標とWCS/UCSの変換、UCSの設定・保存、画面の向き合わせとズーム |
  | `cad-geom.js` | 数学・交点計算、タップ判定、外形と空間索引 |
  | `cad-snap.js` | オブジェクトスナップ（点の収集・選択・記号）、次の1点だけの指定、候補の切り替え、2点の中点、相対入力 |
  | `cad-render.js` | 描画の呼び出し管理、描画キャッシュ、ルーペ、図形・軸・補助表示の描画 |
  | `cad-command.js` | 点入力の補正と各コマンドの処理、オフセット・回転・トリム・延長、コマンド解釈 |
  | `cad-input.js` | マウス・タッチ・キーボードのイベント、パン/ピンチ/範囲選択 |
  | `cad-panels.js` | ブロック管理、画層の一括管理、プロパティパネル、選択アクションバー |
  | `cad-survey.js` | 測量（SIMA・座標CSV、座標一覧、現在地GNSS） |
  | `cad-cogo.js` | 測量計算の計算部分（座標求積・地積の端数・逆計算・放射・交点、求積表の CSV・図面の表、測点の追加） |
  | `cad-cogo-ui.js` | 測量計算のパネル（🧮）、図面での点の指定（`WAITING_DIMCOGO_PT`・区画のタップ）、重ね表示 |
  | `cad-sdr.js` | ソキア SDR 形式（SDR33・SDR2x）の読み込み（観測 → 座標）と SDR33 の書き出し、通信の枠（STX・ETX・チェックサム） |
  | `cad-ts.js` | TS連携のパネル（📡）、Web Serial（USB・Bluetooth）での受信・送信、取り込み前の点の重ね表示 |
  | `cad-storage.js` | 図面の保存・読込（IndexedDB）、自動保存 |
  | `cad-guide.js` | 操作ガイド（ツアー・手順カード・つまずいたときの一言・ヘルプ）。他のファイルは `guideNotify('出来事')` で知らせるだけ |
  | `cad-boot.js` | 起動処理とキー割り当て（**一番最後に読み込む**） |

  `eslint.config.mjs` は `public/*.js` のトップレベル宣言を自動で集めて `globals` にします。ファイルを増やしても登録の追加は不要で、どこにも無い名前（打ち間違い）は今までどおり `no-undef` で見つかります。
* **キャッシュの版管理は自動**: `vite.config.js` のプラグインがビルド時に、`cad-*.js` へ内容ハッシュ（`?v=`）を付け、`dist/sw.js` にビルドIDとプリキャッシュ一覧を書き込みます。**`CACHE_NAME` を手で上げる必要はありません。**
* **エラー記録**: `public/cad-errors.js` が最初に読み込まれ、未捕捉のエラーを画面通知・端末内に記録します。任意の箇所から `window.cadErrors.record(種別, メッセージ, 詳細)` で記録できます。
