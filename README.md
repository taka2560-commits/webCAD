# Antigravity Web CAD

**現在のバージョン: v5.39.1（2026年10月9日リリース）**

[![CI](https://github.com/taka2560-commits/webCAD/actions/workflows/ci.yml/badge.svg)](https://github.com/taka2560-commits/webCAD/actions/workflows/ci.yml)

スマートフォン・タブレット・PC のブラウザで使える、測量・建設現場向けの 2D CAD です。
インストールなしで、DWG・DXF・JWW・SIMA などの図面を開いて、確認・作図・計測・測量計算・書き出しができます。ホーム画面に追加すればアプリとして使え、一度開いた端末なら電波の無い現場でも動きます。

**[https://antigravity-web-cad.vercel.app](https://antigravity-web-cad.vercel.app)**

- 人に渡すとき: アプリの ☰ メニュー →「📱 このアプリを渡す」の QR コードを、相手のスマホのカメラで読み取ってもらいます。
- 使い方の説明: **[WebCAD操作マニュアル.md](WebCAD操作マニュアル.md)**（アプリの中では右下の ？ のヘルプと練習ツアー）
- 版ごとの変更: **[更新履歴.md](更新履歴.md)**

## ✨ 主な特徴

### 📂 図面を開く（上のバーの 📁 開く）
- **DWG**（R2004〜R2018 など。読込エンジン libredwg-web（WebAssembly）を同梱）・**DXF**（文字コード UTF-8・Shift-JIS を自動で判定）・**JWW**（Jw_cad の図面をそのまま。v5.34）・**SIMA**（.sim）・**座標CSV**（プレビューを見ながら列を選ぶ。v5.32）・**SDR**（ソキアの SDR33・SDR2x）・**図面一式**（.webcad。v5.30）。
- 今の図面があるときは「置き換える／今の図面に追加」を選べます。読めなかったときは元の図面に戻ります。ファイルの単位（m・mm）に「図面の1単位」を合わせます。
- 取り込む図形: 線・円・円弧・楕円・ポリライン・スプライン・文字（MTEXT の書式・%%c などの記号も）・寸法・ブロック（属性つき）・塗りつぶし（初めは非表示）・引出線・SOLID。線種・線の太さも取り込みます（v5.27）。取り込めなかった図形は、種類と数を知らせます（v5.26）。
- **レイアウト（ペーパー空間）は別の画面に**（v5.38）: 図枠・表題欄・ビューポートはモデルに混ぜず、画面の下の「モデル｜レイアウト名」のタブで見ます。ビューポートにはモデルが縮尺・回転のとおりに写り、カーソルを置くとモデルの座標が出ます（レイアウトは見るだけ）。

### 📤 書き出す・渡す
- **DXF（AutoCAD 向け）**: 測点は属性つきブロック（点番号・点名・標高）、複数行の文字は MTEXT、寸法は DIMENSION（v5.28）。**DXF（Jw_cad 向け）**: R12・Shift-JIS・mm（v5.29）。
- **SIMA・座標CSV・SDR33**: 書き出す前に、表・ファイルの中身・気づいたこと（点番号の振り直し・Shift-JIS で表せない文字など）を確かめる画面が出ます（v5.37）。
- **図面一式（.webcad）**: 図面・測点・写真・下絵・系番号を1つのファイルにして、別の端末へそのまま渡します（v5.30）。
- **縮尺印刷・PDF**（A4〜A1・1/100〜1/5000、図枠・表題欄・方位記号つきのベクター PDF）・**画面の画像（PNG）**・**写真台帳 PDF**。
- スマホでは書き出したあとに「📤 送る」（LINE・メール・「ファイル」へ。v5.31）。図面一式は LINE でも送れる PDF の形で送り、受け取った PDF は 📁開く でそのまま開けます（v5.39.1）。**このアプリ自体は QR コードで渡せます**（v5.39）。

### ✏️ 描く・直す
- 線分・ポリライン・長方形・円・円弧・楕円・文字・塗りつぶし・点（座標一覧に入る）。
- 移動・複写・回転・削除・オフセット・トリム・延長・鏡像・尺度変更・配列・分割・等分・結合・角の処理（フィレット・面取り）、グリップで点を動かす。
- **線分のタッチ**（v5.35）: 指を離した所は仮の点（緑の輪）になり、☑確定 で線を引きます。画面に触れてしまっても線は引かれません（オプションで「離したらすぐ」にもできます）。↶ 1つ戻す（U）で最後の線を消せます。
- **文字の大きさをまとめて変える**（v5.36）: 選んだ文字・画層・すべてを、種類（点名・寸法の値など）と今の高さで絞り、高さの指定か倍率で変えます。
- 線種（破線・一点鎖線など）と線の太さ（画層・図形ごと）。ブロック・グループ（1回のタップでまとめて選ぶ・分解）。画層一括管理（うっすら表示・タッチで非表示・画層の色）。
- スナップ（端点・中点・中心・交点・垂線・近接点・接線・四半円点・挿入点・延長・図心・等分点）、次の1点だけのスナップ、2点の中点、相対入力、ORTHO、UCS。

### 📏 測る・寸法
- 平行・整列・半径・直径・角度・座標寸法、連続寸法（直列・並列）。
- **基点測定**: 基点からの X 距離・Y 距離・直線距離を出したまま確認し、📐 記入で寸法にします。
- 座標は測量の並び（X＝北・Y＝東）。表示の単位（m・mm）と角度の表示（度・度分秒）を選べます。

### 📍 測量
- **座標一覧**: 測点の検索・タップでその点へ・🗑 で消す、SIMA の読み込み、点名の大きさ（自動・指定）。大きな字で、タブレットや画面いっぱいでは列をそろえた表になります（v5.38.2）。
- **測量計算**: 求積（座標法・地積）・逆計算・点の追加・交点、**SIMA の座標変換（ヘルマート変換）**と精度。
- **杭打ちナビ**（現在地 GNSS から・器械点から）、**TS 連携**（ソキア。SDR ファイル、PC・Android の Chrome では USB・Bluetooth の通信で SDR33・SIMA を送受信）、**現在地**（スマホの GNSS を平面直角座標に）、**現場写真・メモ**（図面にピンと写真。写真台帳 PDF）。

### 🗺 地図・下絵（☰ メニュー →「🗺 地図・下絵」）
- 国土地理院の地図（標準・淡色・**写真**）を図面の下に重ねます（図面の座標を平面直角座標とし、系番号から緯度経度に直します。一度見た範囲は端末に保存）。
- 下絵（地積測量図・公図のスキャン・写真・PDF）を2点で合わせます。ワールドファイル（.jgw・.tfw など）があれば自動で合わせます（v5.33）。

### 📱 現場で使いやすく
- スマホ向けの操作: 2本指で移動・拡大、1本指でなぞるとルーペ、寸法・円・文字・線分は ☑確定 で決めます。押し間違いを戻せる「↩ 元に戻す」つきのお知らせ。
- 屋外モード（太い線・縁取りの文字）、ボタンの大きさ（小〜特大）、デザイン色、⭐ お気に入りのボタン、パネルの ▁ たたむ・□ 画面いっぱい、UIの動き（試用）。
- ヘルプ（❓。ひらがなでも探せる・分類・手順）、練習ツアー、コマンドの手順カード、パネルの見出しの ？。
- PWA: ホーム画面に追加、開くと自動で最新版、オフライン（DWG の読込エンジンと地図は端末に保存できる）、自動保存（変更の15秒後〜60秒・アプリを裏に回したとき）、保存一覧。

## 📱 基本操作

### スマートフォン・タブレット
* **画面を動かす**: 2本指でスライド。**拡大・縮小**: 2本指でつまむ・広げる。上のバーの「🔍 全体」で図面全体。
* **図形を選ぶ**: 図形をタップ（ブロックはまとめて選びます）。選ぶと画面の下にバー（移動・複写・回転・鏡像・尺度・配列・結合・削除・隠す・🔠 文字・グループ化／分解）。
* **点を指定する**: タップするか、1本指でなぞるとルーペが出て点に吸い付きます（緑の印）。指を離した所が点になります（線分・寸法・円・文字は、指を離したあと ☑確定）。
* **範囲で選ぶ**: 下の「範囲」を ON にして、1本指でなぞります（左 → 右は窓選択、右 → 左は交差選択）。
* **文字・寸法を消す**: 長押し（0.6秒）。まちがえたら「↩ 元に戻す」。
* コマンドの途中は、画面の下に ☑確定・↶ 1つ戻す・❌ 終了 などのバーが出ます。

### PC
* **画面を動かす**: マウスの中ボタンを押したままドラッグ。**拡大・縮小**: ホイール。
* **図形を選ぶ**: クリック。**範囲で選ぶ**: 「範囲」を ON にして、何もない所からドラッグ（左 → 右は窓選択、右 → 左は交差選択）。
* **点を指定する**: クリック（スナップの点に吸い付きます）。Esc・右クリックでコマンドをやめます。Ctrl+Z・Ctrl+Y で戻す・やり直し。
* **コマンド欄**（右下の「コマンド」）: コマンド名、座標「X,Y」（X＝北・Y＝東）、相対座標「@X,Y」、数（半径・距離など）を打てます。

### 画面の部品
* **上のバー**: 📁 開く・💾 保存・↩ ↪・画層の選択・👁 画層一括管理・🧩 ブロック管理・🔍 全体・🎯 座標読取（全画面で座標を読む）・📋 プロパティ・☰ メニュー（図面と保存・測量・座標系・表示と設定。画面に収まらないときはスクロール）。
* **左のツールバー**: 描く・直す・寸法・測定（上下にスクロール）。
* **下**: 状態バー（WCS／UCS、モデル／レイアウト名、範囲・ORTHO・OSNAP、座標）、モデル｜レイアウトのタブ（レイアウトのある図面）、右下の ？（ヘルプ）とコマンド。
* **右の浮かぶバー**: ⭐ お気に入りに登録したボタン。

## 🧑‍💻 開発者向け

```bash
npm install          # 依存ライブラリ（dxf-parser / dxf-writer / libredwg-web / pdfjs-dist / qrcode-generator / vite など）
npm run dev          # 開発サーバー（Service Worker は登録されず、常に最新のコードで動作）
npm run build        # 本番ビルド（dist/）
npm run preview      # 本番ビルドの確認（Service Worker・オフライン動作の検証はこちらで）
npm test             # 自動テスト（762件。アプリを jsdom 上で実際に動かして確認）
npm run lint         # 構文・未定義変数のチェック
npm run check        # lint → テスト → ビルドをまとめて実行（CI と同じ内容）
```

* **自動テスト**: `tests/*.test.cjs` は Node.js 標準の `node:test` で動きます。`tests/helpers/load-app.cjs` が index.html と `public/cad-*.js` をブラウザと同じ順序で jsdom 上に読み込むので、テストからアプリの関数・変数をそのまま呼べます（IndexedDB は fake-indexeddb で再現）。不具合を直すときは、先にそれを再現するテストを追加してください。
* **CI**: GitHub にプッシュすると `.github/workflows/ci.yml` が `npm run lint`・`npm test`・`npm run build` を実行します。
* **描画と変更の合図**: 図形や表示位置・選択が変わったら `render()`、カーソル・スナップ記号・ルーペなど重ね表示だけが変わるときは `renderOverlay()` を呼びます（重い図面では前回の画面を再利用します）。図形の座標を変えたら `delete e.bbox` と `_bumpGeomEpoch()` を行ってください（空間索引・描画キャッシュの作り直しの合図。編集前の `saveUndo()` でも進みます）。
* **図形の固有ID**: 各図形は `e.id`（数値）を持ちます。選択状態（`cmdState.selectedIndices` / `highlightIdx` など）は内部ではIDで保持し、読み出すとその時点の配列番号を返します。図形を複製するときは `id` を消してから追加してください（重複しても `ensureEntityIds()` が後ろ側に新しいIDを付けます）。

* **構成**: `index.html` と `public/cad-*.js`（通常のスクリプト）が本体です。外部ライブラリは `src/vendor.js` から Vite で同梱し、`window.DxfParser` / `window.Drawing` / `window.qrcode` / `window.loadLibreDwg()` / `window.loadPdfJs()` として公開しています（DWG の読込エンジンと pdf.js は、使うときに初めて読み込みます）。

  スクリプトは **すべて同じスコープ** に読み込まれるため、ファイルをまたいで関数・変数をそのまま呼び合います。**読み込み順（index.html の並び）と、名前が重ならないこと** が動作の前提です（`tests/structure.test.cjs` で自動確認）。

  | ファイル | 役割 |
  |---|---|
  | `cad-errors.js` | 未捕捉エラーの記録・通知（最初に読み込む） |
  | `cad-theme.js` | デザイン色（標準と暗い5種）。head で読み、`<html>` に CSS の変数を書く（起動のときから色がちらつかない） |
  | `cad-text-parse.js` | DXF文字列のデコード・MTEXT書式の除去 |
  | `cad-dimension.js` | 寸法（6種類）の作成・描画・編集、基点測定の表示 |
  | `cad-io.js` | DXF/DWG の読み込み・書き出し、ファイル選択 |
  | `cad-import-target.js` | 開くときの「置き換える／今の図面に追加」、読めなかったら元の図面に戻す、ファイルの単位（INSUNITS）、レイアウトの図形の見分け |
  | `cad-import-shapes.js` | DXF・DWG 共通の取り込み（塗りつぶしの境界と模様・引出線・マルチ引出線・SOLID・読めない図形の数） |
  | `cad-dwg.js` | DWG の読み込み（libredwg-web の結果 → アプリの図形。ブロック・寸法・レイアウト） |
  | `cad-jww.js` | JWW（Jw_cad の図面）の読み込み（Jw_cad の作者の形式の説明 jwdatafmt.txt と MFC の CArchive の決まり） |
  | `cad-ltype.js` | 線種と線の太さ（取り込み・画面の描画・印刷・DXF の書き出し） |
  | `cad-dxf-out.js` | DXF（AutoCAD 向け）の書き出しの補い（MTEXT・寸法 DIMENSION・属性つきの測点ブロック・塗りつぶし・線種） |
  | `cad-dxf-r12.js` | DXF（Jw_cad 向け）の書き出し（R12・Shift-JIS・mm。寸法・塗りつぶしは線とソリッドに） |
