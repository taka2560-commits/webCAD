# 座標表の読み取りの準備（Claude の API キーの作り方）

Web CAD の「📷 座標表を読む」（v5.55）は、Anthropic の AI「Claude」に写真の座標表を読ませます。使う人が**1人ずつ**、自分の Claude の API キーを作って、自分の端末の Web CAD に入れます。料金は、そのキーの持ち主に読み取った分だけかかります。

PC のブラウザで 10 分ほどです。画面の名前や場所は、Anthropic の都合で変わることがあります。

## 1. Claude Console に入る

1. PC のブラウザで **https://platform.claude.com/** を開き、アカウントを作るか、ログインします。
   - claude.ai（チャット）のアカウントとは別に、API 用の組織（Organization）を作ることがあります。画面の案内に従ってください。

## 2. 料金の払い方を決める（前払い）

1. Console の **Settings → Billing**（請求）で、クレジット（前払いの残高）を買います。初めは少しで大丈夫です（例: $5）。
2. 使いすぎないよう、**Settings → Limits** で月の上限（Spend limit）を決めておくと安心です。

料金の目安（Claude Opus 5.5）:

| 写真 | 料金の目安 |
|---|---|
| 座標表 1 枚（数十点） | 約 $0.02〜$0.10（数円〜十数円） |

- 読み取ったあと、Web CAD の画面の下に、その回の目安（ドル）が出ます。
- 細かく正確に読ませるため、Claude に考える時間を多めに使わせています。表が大きいほど高くなります。

## 3. API キーを作る

1. Console の **Settings → API keys**（または **API Keys**）を開きます。
2. **Create Key**（キーを作る）を押し、名前（例: `WebCAD-iPad`）を付けて作ります。
3. 出てきた **`sk-ant-` で始まる文字**をコピーします。**この画面を閉じると二度と見られません。** 見られなくなったら、作り直します。

キーは、お金を払うカードと同じくらい大事です。

- 人に見せない、メール・LINE で送らないでください。
- 人と共用の端末には入れないでください。
- 漏れたかもしれないときは、Console の API keys でそのキーを消し（Delete / Disable）、作り直します。

## 4. Web CAD に入れる

1. Web CAD の **☰ メニュー → ⚙ オプション** を開き、**📷 座標表の読み取り（Claude）** の「API キー」に、コピーしたキーを貼り付けます。
   - または、☰ → 測量 → **📷 座標表を読む** を押すと、キーを入れる欄が出ます。
2. 「✅ キーが入っています」と出れば準備は終わりです。キーはこの端末にだけ覚えます。スマホ・タブレット・PC で使うときは、それぞれで入れます。
   - 人と共用の端末・人に貸す端末では、**「この端末に覚えない」** にチェックを入れてから入れます。アプリを閉じるとキーが消えます。

### キーを守る仕組み（Web CAD の側）

- キーはこの端末のブラウザの中にだけ置き、Anthropic（api.anthropic.com）にだけ送ります。アプリの中ではこのアプリのスクリプトだけが動き、通信先は Anthropic・Dropbox・国土地理院の地図に限っています（CSP）。
- 保存・図面一式・書き出したファイルには、キーは入りません。
- コマンド欄・知らせ・エラーの記録では、キーに見える文字を「（隠しました）」にします。
- キーの欄は伏せ字で、入れたあとは空になります。

### 自分でしておくこと

- Claude Console の **Settings → Limits** で、月の上限（Spend limit）を決めておきます。万一漏れても、それ以上の料金はかかりません。
- Web CAD 専用のキーを作り、ほかのことには使いません。漏れたかもしれないときは、Console でそのキーだけを消して作り直します。
- 端末には画面のロック（パスコード）をかけておきます。

## 5. 使い方

1. ☰ → 測量 → **📷 座標表を読む** → **📷 写真・PDF を選ぶ**。
   - 表を真上から、影を入れずに、表がいっぱいに写るように撮ります。
   - 1 枚に入らない表は分けて撮り、まとめて選びます（5 枚まで）。
2. 1 分ほどで、読み取った表が出ます。元の写真（押すと大きく）と見比べて、違う所を直します。
   - **色の付いた行**は Claude が自信の無い行で、理由が出ます。
   - X・Y が数でない行は取り込みません。直すか、「入れる」を外します。
   - 表が mm なら「表の値は mm」を入にします。東・北の順の表なら「⇄ X と Y を入れ替える」を押します。
3. **📥 ○点を取り込む** で座標一覧に入ります（今の図面があれば、置き換えるか追加するかを聞きます）。

## うまくいかないとき

| 出ること | 直し方 |
|---|---|
| 「API キーが違うか、使えなくなっています」 | キーをもう一度コピーして入れ直す。Console でキーが消されていないか確かめる |
| 「この API キーでは読み取れません」 | Console の Billing で残高・支払いを確かめる |
| 「使える量の上限に達しました」 | 少し待つ。Console の Limits で上限を確かめる |
| 「Claude がこの画像の読み取りを断りました」 | 座標表だけが写るように撮り直す |
| 「通信できませんでした」 | 電波のある所でもう一度（読み取りは電波が要ります） |
| 読み間違いが多い | 明るい所で、真上から、表を大きく撮り直す。細かい表は分けて撮る |

## 送られるもの

読み取る写真（または PDF）は、Anthropic の Claude に送られます。客先の資料を送ってよいかは、契約などで確かめてください。キー自体は Anthropic にだけ送られ、Web CAD の作者には届きません。
