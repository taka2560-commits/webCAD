# 品質管理ゲート

Web CAD を main に出す前に通す関門です。**いちばん大事なのは計算を間違えないこと**です。
`npm run check` が G1・G2 と計算ゲートをまとめて走らせ、CI（GitHub Actions）も同じものを走らせます。G3 は人（または Claude の別の担当）が行う点検です。

## 変更の大きさと、通すゲート

| 変更 | 通すゲート |
|---|---|
| 説明・文言だけ | G1 |
| **計算**（座標・距離・角度・面積・変換・交点・測量計算・寸法の値・単位） | G1（計算ゲート）＋ G3 |
| 画面・操作（ボタン・パネル・指の動き・動き） | G1 ＋ G2 ＋ G3 |
| 公開の仕組み（manifest・sw.js・共有） | G1 ＋ G2 ＋ 公開後に実機で確かめる |

## G1 自動チェック（`npm run check` の中）

| 何を | どこで | 止める条件 |
|---|---|---|
| 構文・未定義の名前 | `npm run lint`（eslint） | エラー 1 件でも |
| 自動テスト（jsdom でアプリを動かす） | `npm test` | 失敗 1 件でも |
| **計算ゲート** | `tests/calc-gate.test.cjs`・`tests/helpers/calc-oracle.cjs` | 下の「計算ゲート」 |
| 値の監査（画面・DXF・記録に出る数の文字） | `tests/values-audit-*.test.cjs`・`tests/helpers/values-oracle.cjs` | 1 文字でも違う |
| 見えない文字・版番号・テストの件数 | `npm run quality`（`scripts/quality/check.mjs`） | 見えない文字がある・README／マニュアル／更新履歴の版が違う・README の件数が実際と違う |
| 本番ビルド | `npm run build` | 失敗 |

### 計算ゲート（計算は絶対に間違えない）

- **別の式で照らす**: アプリの計算の関数ごとに、テストの中に**アプリのコードを使わずに書いた式**（`calc-oracle.cjs`）を置き、同じ入力で答えを比べる。
- **決まった難しい例と、乱数の大量の例**: 0・負・軸に平行・ほぼ平行・公共座標の大きな値・とても短い／長い距離・0°／90°／180°／270°／360° の近く・mm の図面、に加えて、種を決めた乱数で 1 関数あたり 300 件以上。
- **許す差を書いておく**: 例 幾何は 1e-9 m、角度は 1e-9°、平面直角座標は式どうしで 1 mm 以内・行って戻って 1e-9°。
- **登録の決まり**: 計算の関数（名前の決まりで探す）が照合に入っていなければ、テストが落ちる（「新しい計算の関数は calc-gate に照合を足してください」）。照合しない関数は理由を書いて除外の表に入れる。
- **食い違いが見つかったら**: 照合の式とアプリのどちらが正しいかを、手計算・公表の値で確かめてから直す。照合の式を緩めて通さない。

## G2 画面のチェック（`npm run ui-gate`）

本物の Chrome（`playwright-core`。PC に入っている Chrome を使う）で、ビルドしたアプリを開いて確かめる。

- 組み合わせ: 幅（スマホ 390・タブレット横 1024・縦 768・PC 1366）× ボタンの大きさ（中・特大）、動き 入 を 1 通り。
- 見た目: 上のバー・ツールバー・下の欄が画面に収まり重ならない、横にスクロールしない、パネル（オプション・座標一覧・UCS 管理）が収まる。
- 指の操作: 点の横の ☑確定 が画面の中・下のバーと重ならずに出て、押すと決まる。OSNAP の長押し → 滑らせて離すとスナップが切り替わって閉じる（OSNAP は切れない）。
- エラー: pageerror・console.error・読み込めないファイルが無い。
- 撮った画面は `.quality/ui/` に置く（CI で失敗したときは画像を artifacts に残す）。
- 新しい画面・操作を足したら、ここにも確かめる手順を足す。

## G3 組み合わせの点検（新しい機能を入れたとき）

作った人とは別の担当（Claude のサブエージェント）が、**壊すつもりで**点検する。見つけた不具合は、直したうえで再現するテストを足す。

### 必ず通す点検項目

1. ↩（元に戻す）・やり直し（図形だけでなく、その機能が持っている状態も戻るか）
2. 保存して開き直す・図面一式（.webcad・PDF）で渡す・自動保存の復元
3. 図面の1単位 m ／ mm、表示の単位、UCS が入っているとき、画面の回転（PLAN）
4. レイアウトを見ているとき・全画面（座標読取）・パネルを開いているとき・スマホの幅
5. コマンドの途中で別のコマンド・Esc・❌・図面を閉じる・別のファイルを開く（置き換え／追加）
6. 指とマウスの両方、オプション（ボタンの大きさ・動き・確定ボタンの位置など）を変えたとき
7. 計算に関わるなら: 大きな座標（公共座標）・0 や平行などの境目・選んだ図形だけ／すべて

### 頼み方（ひな形）

> この機能（ファイル・関数）を、上の点検項目 1〜7 で壊すつもりで点検してください。リポジトリは変えず、再現スクリプトは scratchpad に。
> 確かめた不具合だけを、場所（ファイル:行）・再現の手順・重さ・直し方で報告。確かめきれないものは別に短く。

### 記録

点検の結果と直したものは、更新履歴の「点検で見つかった不具合を直す」の版に書く。

## 実機でしか確かめられないもの

LINE で送る・Android の「アプリで開く」「共有」・iPhone の保存・タブレットでの指の操作感・バネなどの動き。
これらは更新履歴とメモリーの「確認待ち」に残し、ユーザーに試してもらう。
