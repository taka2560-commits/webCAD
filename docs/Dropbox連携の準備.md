# Dropbox 連携の準備（アプリキーの作り方）

Web CAD の「☁ Dropbox から開く」「☁ Dropbox へ」（v5.54・v5.56）を使うには、使う人が**1人ずつ**、Dropbox で自分用の「アプリ」を作り、その **App key（アプリキー）** を Web CAD に入れます。PC のブラウザで 10 分ほどです。費用はかかりません。

## 1. Dropbox でアプリを作る

1. PC のブラウザで https://www.dropbox.com/developers/apps を開き、ふだん使っている Dropbox のアカウントでログインします。
2. **「Create app」**（アプリを作成）を押します。
3. 次のように選びます。
   - **1. Choose an API**: 「**Scoped access**」
   - **2. Choose the type of access you need**: 「**Full Dropbox**」（Dropbox のフォルダをたどって開き、開いた図面と同じフォルダに保存するため）
     - 「App folder」を選ぶと、開く・保存する場所が「アプリ／（アプリ名）」フォルダの中だけになります。
   - **3. Name your app**: 好きな名前（例: `WebCAD-taka`）。ほかの人と同じ名前は使えません。
4. 同意のチェックを入れて **「Create app」** を押します。

## 2. 使う権限を選ぶ（Permissions のタブ）

1. 作ったアプリの画面の上の **「Permissions」** タブを開きます。
2. 次の 3 つにチェックを入れます。
   - `files.metadata.read`（フォルダの中を見る・開いたファイルのフォルダを知る）
   - `files.content.read`（ファイルを読む＝開く）
   - `files.content.write`（ファイルを保存する）
3. いちばん下の **「Submit」** を押します。

※ 権限は、Web CAD で「つなぐ」**前に**決めておきます。あとで変えたときは、Web CAD で「接続を切る」→「つなぐ」をやり直します。

※ v5.55 までに準備した人へ: v5.56 から、開くのにも `files.content.read` が要ります（Dropbox の部品をアプリの中で動かさないようにしたため）。チェックを足して Submit し、Web CAD で「つなぐ」をやり直してください。

## 3. 設定（Settings のタブ）

1. **「Settings」** タブを開きます。
2. **App key** の値（英数字 15 文字ほど）をコピーします。これが Web CAD に入れるアプリキーです。
   - 隣の **App secret** は使いません。「Show」も押さず、人にも渡さないでください。
3. **Allow public clients (Implicit Grant & PKCE)** は「**Allow**」のままにします。
4. **OAuth 2 → Redirect URIs** は空のままで大丈夫です（Web CAD は、出てきたコードを貼り付ける形でつなぎます）。
5. **Chooser / Saver / Embedder domains** は使いません（空のままで大丈夫です。v5.55 までに足した人は、そのままでも消しても構いません）。
6. **Generated access token** は押しません。

※ 作ったばかりのアプリは「Development」（開発中）で、「Development users: Only you」です。準備は**1人ずつ自分の Dropbox で**するので、そのままで使えます（「Apply for production」「Enable additional users」は要りません）。

## 4. Web CAD にアプリキーを入れて、つなぐ

1. Web CAD の **☰ メニュー → ⚙ オプション** を開き、**☁ Dropbox** の「アプリキー」に、コピーした App key を貼り付けます。
   - キーは端末ごとに覚えます。スマホ・タブレット・PC で使うときは、それぞれの Web CAD に同じキーを入れ、それぞれで「つなぐ」をします。
   - ほかの人は、その人の Dropbox で 1〜3 をして、その人のキーを使います（アプリにキーは組み込みません）。
2. **つなぐ（1 回だけ）**: オプションの **☁ つなぐ** を押します。
   1. 出てきた欄の **☁ Dropbox の画面を開く** を押し、ログインして「許可」（Allow）を押します。
   2. 画面にコードが出るので、コピーします。
   3. Web CAD に戻り、「Dropbox につなぐ」の欄に貼り付けて **☁ つなぐ** を押します（コードは 30 分のうちに貼り付けます）。
3. **開く**: ☰ → **☁ Dropbox から開く** で、Web CAD の中に Dropbox のフォルダの一覧が出ます。フォルダを押してたどり、ファイルを押すと開きます。
   - 出るのは開けるファイル（DXF・DWG・JWW・SIMA・座標CSV・SDR・図面一式）とフォルダだけです。
   - 上の「Dropbox / 案件 / …」を押すと、そのフォルダに戻ります。
4. **保存**: DXF・SIMA・図面一式などを書き出すと、知らせに **☁ Dropbox へ** が出るので押します。
   - Dropbox から開いた図面は、そのファイルと同じフォルダに保存します。
   - ほかの図面は、オプションの「保存先」（初めは `/WebCAD`）に保存します。
   - 同じ名前のファイルがあると、「名前 (1).dxf」のように別の名前で保存します（上書きしません）。

## 守る仕組み

- Dropbox につないだ印（token）は、この端末のブラウザの中にだけ置き、Dropbox にだけ送ります。
- Dropbox の部品（スクリプト）はアプリの中で動かしません。一覧も Web CAD が自分で出します。
- 「接続を切る」を押すと、端末から消すだけでなく、Dropbox 側の許可も取り消します。アプリキーを変えたときも、前の許可を取り消します。
- やめるときは、Dropbox の App Console で作ったアプリを開き、Settings のいちばん下の「Delete app」で消せます。

## うまくいかないとき

| 出ること | 直し方 |
|---|---|
| 「Dropbox の許可が足りません」 | 2 の権限 3 つにチェックを入れて Submit し、Web CAD で「☁ つなぐ」をやり直す |
| つなぐときに「invalid_scope」「missing scope」 | 2 の権限 3 つにチェックを入れて Submit し、Web CAD で「接続を切る」→「つなぐ」をやり直す |
| 「コードは 1 回しか使えません」 | 「つなぐ」をもう一度押し、新しいコードを 30 分のうちに貼り付ける |
| 「許可が切れました」 | オプションの「☁ つなぐ」をやり直す（Dropbox の設定でアプリの接続を外したときなど） |
| 一覧にファイルが出ない | 開ける種類（DXF・DWG・JWW・SIMA・座標CSV・SDR・図面一式）か確かめる。ほかの種類は出しません |
