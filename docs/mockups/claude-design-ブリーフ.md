# Claude Design 用ブリーフ（webCAD モバイルUI 整え）

このファイルは claude.ai/design でデザインを調整するための「渡す素材」と「手順」をまとめたものです。

---

## ■ 使い方（手順）

1. ブラウザで **https://claude.ai/design** を開く（あなたのアカウントでログイン）。
2. 新しいデザイン（New design / プロジェクト）を作成。
3. 下の「**② プロンプト（コピペ用）**」を貼り付ける。
4. あわせて、モック画面の**スクリーンショット画像**を添付すると精度が上がります。
   - モックを開く: `docs/mockups/ui-mock-mobile.html`（ローカルサーバー: `http://localhost:8899/docs/mockups/ui-mock-mobile.html`）
   - 「通常モード」「座標読取モード（ドロワー開/閉）」の3枚を撮って添付。
5. 生成された案を見て、チャットで「もっと余白を」「ボタンを丸く」等と指示して詰める。
6. 気に入った案が出たら、その画面のスクショ or 生成コードを**こちらに渡してください**。
   → 私が `index.html`（バニラHTML/CSS）に翻訳して反映します。

> 注意: Claude Design の出力は **React** です。この webCAD はバニラHTML/CSSなので、
> 見た目を私が手作業でCSSへ移植します。プロンプトでは「移植しやすいよう素のCSSと
> CSS変数で」と指定済みです。

---

## ② プロンプト（コピペ用）

```
あなたはCADソフトのモバイルUIデザイナーです。
既存のWeb CADアプリ（製造業の現場で座標計測・作図に使用）のUIを、
「今の構造・操作体系は崩さず、見た目とタッチ操作性だけを整える」方針で
リデザインしてください。最優先端末は iPhone 縦持ち（幅 ~390-414px）です。

# 重要な制約
- 既存レイアウトの骨格は維持する（タブやボトムシート等への大規模再構成はしない）。
- 暗背景のCADテーマを維持。配色は下記トークンを基準に微調整のみ。
- 出力はバニラHTML/CSSへ移植する前提。素のCSS + CSS変数で書き、
  特定フレームワーク固有の仕組みに依存しない見た目にする。
- ラベルは日本語のまま（後述の文言を使用）。

# 配色トークン（現行を踏襲）
--bg:#212830  (キャンバス/全体背景)
--panel:#333842 (バー類)
--panel-2:#2a2e35 (カード/グループ)
--border:#181c21
--text:#e0e0e0  --dim:#9aa3ad (補助文字)
--accent:#528bff (青) --green:#00ff88 (強調) --cyan:#00ffff (寸法) --yellow:#ffcc00 --warn:#ff6b6b
- 最小タップ領域は 40px 以上、角丸は 8〜12px で統一。

# 画面1: 通常編集モード（縦持ち）
- 上部バー（横1行・横スクロール、折返ししない）:
  「📁開く / ✕閉じる / 📋プロパティ / [保存: 💾 📂 DXF DWG] / [編集: ↩ ↪]
   / [座標系: WCS, UCS選択, 🧭PLAN, 原点移動, 2点] / [画層: 色, 0, 👁️, 🚫]
   / 🔍原点 / 🔍全体 / 🎯座標読取」
  ボタンは高さ統一・余白を揃えて押しやすく。グループはカード化。
- ステータスバー（細い1行）: 「WCS モデル | 範囲選択 | ORTHO | OSNAP▾ | 座標値」
- 中央: 左に縦ツールバー（幅60px前後）＋ 黒キャンバス。
  左ツールバーのボタン: 作図(LINE/PLINE/RECT/CIRCLE/ARC/ELLIP/TEXT/HATCH)
  ─区切り─ 編集(ERASE/MOVE/COPY/OFFSET/ROTATE)
  ─区切り─ 寸法(DIMLIN/DIMALN/DIMRAD/DIMDIA/DIMANG/DIMORD)。
  各ボタンはアイコン＋小ラベル、選択中は青ハイライト。区切り線でカテゴリ分け。
- 下部: コマンドライン（ログ＋入力欄、等幅フォント）。

# 画面2: 座標読取モード（全画面・現場用）
- 全画面の黒キャンバス。UI要素は最小限のフローティング。
- 上部に細い半透明ステータス（WCS/範囲選択/ORTHO/OSNAP▾/座標値）。
- カーソル付近に座標ツールチップ（緑文字・等幅、X/Y/スナップ種別。現場で読めるよう大きめ）。
- 左下: 縦ズーム（＋ / 縦スライダー / −、丸ボタン）。
- 右下: 丸FAB縦4つ（⊕OSNAP / XY座標常時表示 / ⛶全体 / ✕解除）。50px・等間隔。
- 右端: 引き出しドロワー（◀タブで開閉）。中身は3グループ:
  1) 📍座標 / ✏連続寸法
  2) 🎯UCS / 📈2点 / 🧭PLAN / ↩WCS / UCS読込(選択) / 画層(選択)
     / [👁️画層管理 | 🚫タッチ消去] / [💾保存 | 🗑️消去]
  3) 💾図面保存 / 📂復元
  ボタンは高さ38px前後で統一、角丸・余白を揃えて詰まりを解消。

# 仕上げ
- 全体に余白・整列・コントラストを整え、現場でも視認しやすく。
- backdrop-blur・控えめな影でフローティング要素を浮かせる（現行の雰囲気を踏襲）。
- まず縦持ちスマホ幅で完成度を上げ、その後タブレット幅にも破綻なく対応。
```

## ③ 参考: 現行の主な実測値（プロンプト補足用）

- 上部バー: ボタン高さ ~36px、グループ間 gap 8px
- 座標読取モード: FAB 50px、ズーム丸ボタン 40px、スライダー高さ ~130px
- フォント: UI = Segoe UI / Hiragino、コマンド・座標 = Consolas（等幅）
